# pieris.celldeath.brapa.QTLmapping

This repository contains the datasets and code used in the study *"Genetic analysis reveals three novel QTLs underpinning a butterfly egg-induced hypersensitive response-like cell death in Brassica rapa"* of Bassetti et al. 2021. *BMC Plant Biology* 22: 1–17. https://doi.org/10.1186/s12870-022-03522-y

For details on files content and use of scripts, see "README_pieris.celldeath.brapa.qtl.txt"
